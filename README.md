## Strawberry Shortcake Website

A static, multi-page fan website based on the 2003 Strawberry Shortcake series.

This project was created for my Web Development Fundamentals module during semester 1 of first year. 
The aim was to apply the HTML5 and CSS3 skill that were learnt in the module to build my first website from scratch. 
The project help me to understand HTML structure, CSS styling, page layouts, navigation, forms, and basic JavaScript while building my first website from scratch.


## Features

- Character, pet, and production history content
- Pages for resources, frequently asked questions, contact details, and a competition
- A responsive navigation menu and shared colour scheme
- An embedded YouTube video, Google Map, and Twitter timeline
- An interactive JavaScript page with prompts, character image controls, and a pet game
- A competition form that submits data to an external form-display service
- Custom Strawberry Shortcake artwork and favicon

## Pages

| Page | Description |
| --- | --- |
| `Home.html` | Main fan-site page with character and pet profiles, franchise history, and videos |
| `Resources.html` | Merchandise and external Strawberry Shortcake reference links |
| `Competition.html` | Monthly competition entry form |
| `ContactUs.html` | Contact information and an embedded social timeline |
| `FAQ.html` | Answers to common questions about the series |
| `Project-Java.html` | JavaScript demonstrations and an interactive pet game |

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Embedded YouTube, Google Maps, and Twitter content

## Getting Started

The website has no build step or package dependencies. To view it locally:

1. Clone or download this repository.
2. Open `Home.html` in a web browser.
